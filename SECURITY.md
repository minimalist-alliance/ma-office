# Security

## Reporting a vulnerability

Email **support@minimalistalliance.com** with "Security" in the subject. Please include what you found, how to
reproduce it, and what it affects. Don't open a public issue or pull request for a vulnerability, and don't test
against other people's desks or data.

We'll confirm we got your report within a few days, keep you posted while we fix it, and credit you when the fix
ships if you'd like.

## Scope

This repository: the office web app, the desk image and its services (`deskd`, `desk-rtc`, `desk-agent`, Notebook,
Commons), self-hosting and the desk tools. The hosted platform is in scope too when the issue is in how it uses this
code.

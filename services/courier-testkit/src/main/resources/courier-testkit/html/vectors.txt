# Hostile HTML vectors for Courier's sanitizer and for a real-browser check of what it lets through.
# Written fresh for this test kit from the categories of the OWASP XSS Filter Evasion Cheat Sheet and
# html5sec; nothing here is copied from those pages.
#
# Format:
# - Lines starting with '#' before the first vector are comments, and so are blank lines there.
# - A vector starts with a line "== <name>". Its HTML is every following line up to the next line that
#   starts with "== " (or the end of the file), joined with "\n", with trailing blank lines removed.
#   Inside a vector, a line starting with '#' is part of the HTML, not a comment: comments live only here.
# - Names are lowercase [a-z0-9-]+ and unique.
# - Placeholders, filled by HostileHtml.vectors(hitBase):
#     {{HIT}}     the counting host for this vector: hitBase + "/" + name, for example
#                 http://127.0.0.1:PORT/hit/<name>
#     {{HIT//}}   the same without the scheme, for protocol-relative vectors: //127.0.0.1:PORT/hit/<name>
#     {{U+hhhh}}  one code point, 4 to 6 hex digits, for NUL, CR, tab, form feed, zero-width characters
#                 and the like, so the file itself holds no control bytes.
# - Every vector holds the literal text "alert(" (it calls alert(1) when it runs) or "{{HIT" (it fetches
#   that URL when it loads), so a browser check can count both. Some need a click or a focus; a few are
#   legacy shapes that only old engines ran, kept because a sanitizer must still remove them.
# - Hosts: only the placeholders, plus attacker.example where a second host is needed.

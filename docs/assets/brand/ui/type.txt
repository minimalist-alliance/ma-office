Don't vendor anything: it arrives through npm, like Inter and Jost.

CSP
Works with no change. Checked in a release build behind the harness's default policy, in all three themes:
  default-src 'self'; connect-src 'self'; img-src 'self' data: blob:; media-src 'self' blob:; worker-src 'self' blob:; frame-ancestors 'none'
Result: Nunito and Jost load from 'self' with status 200, no console or CSP errors, and Inter isn't requested. No CDN. No data: fonts, because vite.config.ts keeps assetsInlineLimit at 0.
Fonts follow default-src. Platform's real loader wasn't tested. If its policy differs from the harness, font-src must still allow 'self'.
Sign-in pages: self-host the same file on each app's host. The Google Fonts link in mock.html is for the mock only.

FALLBACK WITH METRIC ADJUSTMENT
  @font-face {
    font-family: "Nunito Fallback";
    src: local("Arial"), local("Liberation Sans"), local("Arimo"), local("Helvetica");
    size-adjust: 102.7%; ascent-override: 98.4%; descent-override: 34.6%; line-gap-override: 0%;
  }
Measured against Arimo, which has Arial's metrics, for Nunito at 600, the weight most UI text uses. Arial itself isn't installed on this machine.
Ascent and descent match exactly. Width as a share of Nunito's:
  text                                           plain  adjusted
  Your notes will live on this desk, and only     0.974  0.999
  Notebook isn't built yet                        0.945  0.971
  Personal                                        0.989  1.016
  Plain background                                0.974  1.001

  switch desks, scroll to zoom, drag to pan, p    0.978  1.004
  Sam: the draft is ready for a look              0.977  1.001
Worst case -3% to +1.6%, against -5.5% without it. Put this rule in the app's own CSS, since the package doesn't ship it.
Limits: a device with none of those local fonts (some Android and Linux) falls to system-ui, unadjusted. Canvas doesn't benefit much: fontsReady waits up to 800 ms before the first draw, and tile text drawn on a fallback stays until the next redraw, which is today's behavior with Inter.

WEIGHTS BY ROLE: the rule
  11-14 px: 600. Titles at those sizes: 700.
  15-16 px: running text 500 (sign-in only; the app has none at this size), controls 600, headings and selected states 700.
  24 px: 500 for the app's quiet h1. The 26 px sign-in h1 is 700, because it carries the page.
Judged by eye at 1x and 2x on Light and Dark, in DOM and canvas. 500 read thin at 1x beside Inter 400. 600 matched its color. See final-small-text.png.
No tracking was added. One size changed: the desk nav's small line, 11 to 12 px, because Nunito's x-height is lower than Inter's.

Canvas text scales with the camera, so one weight has to serve every zoom. 600 is right at 100%, and a little strong at 175% and up, where the rule would pick 500. The variable font would allow a swap on settle, as the etch does with settledLod, but I don't think it's worth the code.

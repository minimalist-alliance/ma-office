# Minimalist Alliance — brand

The Minimalist Alliance name and logo are trademarks of Minimalist Alliance LLC and are not covered by this repository's license: see [`TRADEMARKS.md`](../../../TRADEMARKS.md). The mark is an "M" made of two ribbons, the right one wrapping over the left (ADR 0066). The brand kit itself (logo files, lockups, app icons) is not published here; the app carries only the files it uses (`web/src/assets/brand/`, `web/public/`).

## What's here
- `ui/tokens.json`: the apps' color tokens for Light, Dusk and Dark (ADR 0065). `tokens.ts` in each app reads these values.
- `ui/type.txt`: the type scale, in Nunito (ADR 0065).
- `ui/contrast.txt`: contrast checks for the tokens.

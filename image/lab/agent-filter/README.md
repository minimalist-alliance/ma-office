# ADR 0070's measuring tools, outside any bake

- `load/`: a stand-in provider and the clients that measure the filter on it. `go build` for arm64 and run it on two boxes: `load serve` on one with a public address, and the rest on the desk as uid 1103 (through the filter) or uid 1102 (direct, the same shaper class). The name goes in `/etc/hosts` and `/etc/ma/agent-egress.conf` on the desk while measuring. No keys, and no traffic to a provider except `load ttfb -verify` against `/v1/models`, whose 401 is the answer.
- `JdkProbe.java`: one request with the JDK's HTTP client, as `desk-agent`'s `HttpTransport` makes them, run in `desk-agent`'s own image as uid 1103. `javac --release 21`, then `--entrypoint java` with the class mounted.
- `lab.sh`: a lab box from any AMI, tagged `Purpose=desk-image-build`, SSH from this workstation only, its key in `$S/lab/<name>` outside the repo. `lab.sh down <name>` removes the box, its key pair and its group. Then check by tag that nothing is left.
- `measure.sh` and `measure-box.sh`: the numbers in ADR 0070, one run on box a (from the image under test, or with the release under test installed by `ma-update` with its unit) against `load serve` on a stand-in box (stock Debian 13 arm64). `measure-box.sh` runs on box a as a transient unit and `measure.sh` copies its output to `$S/numbers.txt` every 20 s, so a cut-off on the workstation neither stops it nor leaves a second run to overlap it. Run it alone on its box, once.
- **Keep the stand-in on a private address in a's zone** (`SUBNET=<a's subnet> lab.sh up c ...`, then `B=c PRIVATE=1 measure.sh`): it costs nothing and stays off the public path. The filter refuses private addresses, so for that run `measure.sh` swaps in a lab build, `lab-private-standin.patch` on the release's source built to `$S/filter-lab`, with `MA_FILTER_LAB_ALLOW` naming the stand-in and one nftables rule letting uid 1106 reach it on 443. It takes all three off and puts the release back at the end. **Platform's cost guard stops a box that sends 30 GB in 15 minutes:** it stopped a public stand-in after two explorations sent about 46 GB. One `measure-box.sh` run is about 5 GB; keep any 15 minutes under 10.
- `mutate.sh` and `mutants.txt`: each thing `verify-agent-filter.sh` guards, broken on box a, and its check seen to fail. `mutants.txt` is the one-line change in each program mutant; build each for arm64 into `$M/<name>/bin`. The rules' and the unit's breaks are in the script. Takes about 35 minutes, and needs no stand-in.

How each was run, and what it found: `../../evidence/agent-filter-2026-11-07/` (`numbers.txt`, `mutations.txt`). The checks that keep the filter true are `../../verify-agent-filter.sh`, section 3e1 of `verify.sh`.
